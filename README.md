# Loan Default Analysis using Python & Power BI

## Project Overview

This project focuses on analyzing loan default patterns using Python for Exploratory Data Analysis (EDA) and Power BI for interactive dashboard visualization.

The goal of this project is to identify the key factors influencing loan defaults and provide meaningful business insights that can help financial institutions reduce lending risks.

### Visualization Tool

---

## Key Insights

### Financial Factors
- Higher income borrowers tend to default less
- Higher credit scores reduce default probability
- Larger loan amounts are associated with increased default risk
- Higher interest rates correlate with higher defaults
- Longer loan terms show increased default rates

### Demographic Insights
- Younger borrowers have higher default tendencies
- Borrowers with lower education levels show more defaults
- Divorced individuals show relatively higher default rates
- Customers without mortgages are more likely to default

### Loan Purpose Analysis
- Business loans have higher default rates
- Home loans show comparatively lower default risk
